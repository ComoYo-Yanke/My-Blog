# 04 · 天空岛与诸神

> 本文件整理**天空岛（Celestia）**、**天理**、**魔神体系**、**神的死亡与磨损**，以及各篇章中登场的神明与魔神。

---

## 一、天空岛（Celestia）

- **天空岛**是悬浮在提瓦特上空的岛屿/城邦，是天理与天空岛使者的居所。
- 神之眼的授予被认为与天空岛有关；「升入天空岛」是极少数人类（如**温妮莎**）能达到的终点。
- 天空岛对人类的态度是**「授予 + 戒备」**：赐予神之眼，也会对越界者降下天罚（如寒天之钉）。
- 天空岛与提瓦特地面之间的通信/联系机制，在 5.x–7.x 才被逐步揭示，仍有大量空白。

---

## 二、天理（Heavenly Principles）

- **天理**既是「法则」，也是被拟人化称呼的存在。
- 它由**原初之人法涅斯**奠定，其下有**四影**（生 / 时 / 死 / 空）。
- 坎瑞亚被视为「触犯天理」而被灭，说明天理对「人类获取超出许可的力量」有明确的红线。
- 全作的主线问题之一：**天理究竟是人格神，还是一套自我运行的规则？**

### 四影（原初四执政）名单

| 影子 | 名讳 | 要点 |
|---|---|---|
| **生之执政** | **纳贝里士** → 后由**莱茵多特**接任 | 【存疑但已可弥合】萌娘百科四影栏列「生之执政＝纳贝里士」；7.1 官方宣发与英文媒体均称**莱茵多特**。较通行的弥合说法：莱茵多特与阿贝多在地底找到**「纳贝里士之心」**后，莱茵多特**吞噬此心而成为生之执政**（她还是坎瑞亚五大罪人之一「黄金」）。6.x 第九/十幕中，生之执政曾在主线直接与纳西妲对话。 |
| **死之执政** | **若娜瓦**（Ronova） | 五百年前降下「不死诅咒」；7.1 至冬篇的周本 Boss 与被收回权能者。 |
| **时之执政** | **伊斯塔露** | 蒙德、稻妻、坎瑞亚多处留下痕迹；6.x 第九/十幕与纳西妲对话时称：「世界樹乃原初的提瓦特之樹，是天理用以維護命運的重要命脈。七執政自天理手中接過權柄。」 |
| **空之执政** | **阿斯莫代** | 与「天理的维系者」相关；7.1 被目击与一名兜帽身影（疑为深渊血亲）同行【存疑】。 |

- 【高】**生、死、时、空这四种权能原本属于月亮**，月亮被毁后天理把权能收回并分给四影（详见 [13_挪德卡莱_空月之歌](13_挪德卡莱_空月之歌.md)）。
- 【高】6.x 第九/十幕是**四影在主线中首次直接现身**：死之执政、时之执政、生之执政与纳西妲对话，并默许她行使「毁灭世界树的最高权限」。
- 【高】因天理陷入**沉睡／休眠**，天空岛从「持续监控世界」改为**「周期性监控」**——这成为执政与世界各方钻空子的前提。

## 三、七神体系

- **七神 = 魔神战争的七位胜者**，各自获得一种元素与一片国土。
- 七神持有**神之心**（Gnosis），并各自奉行一种理念（自由 / 契约 / 永恒 / 智慧 / 公正 / 战争 / 怜爱）。
- 七神并非一律强盛：有的沉睡（巴巴托斯）、有的隐世（摩拉克斯退位）、有的自我分裂（雷电影造人偶）、有的献祭（芙卡洛斯）。
- **神的「理念」往往来自创伤**：
  - 雷电影因雷电真之死追求永恒；
  - 芙卡洛斯因枫丹的「原罪」选择自毁神座；
  - 冰之女皇的动机与「怜爱」相关（待考）。

## 五、神的磨损与死亡

- **「磨损」（Erosion）**：长生种在漫长时间中精神与自我被消磨的现象。
  - 岩神摩拉克斯以「退位」应对；
  - 雷电影以「永恒」和「冥想」应对；
  - 魈以「业障」承担同类痛苦。
- **神的死亡**不等于世界的崩塌，但会引发权力真空（璃月帝君之死）或制度性危机（枫丹预言）。
- **神之心的剥离**并不使神立刻失去力量，但会削弱其与天空岛的联结（三大神之心先后被夺 / 主动交出）。

## 七、天空岛体系的「人」

- **天空岛使者 / 神使**：负责传达天理意志的存在。
- **仙人 / 眷属**：依附于某位神明的长生种族（如璃月仙人、八重神子、风魔龙特瓦林）。
- **半神 / 混血**：如甘雨（麒麟与人）、烟绯（半仙）。
- **人造生命**：坎瑞亚技术的产物（阿贝多、杜林、雷电将军人偶、散兵），与「神造人」主题直接呼应。
