# 16 · 未解之谜与推测

> 本文件汇总截止 7.1 版本**尚未被官方明确回答**的问题，以及社区主流推测。
> ⚠️ 所有「推测」条目标注了可信度：**【高】**有较多文本支撑 / **【中】**有旁证 / **【低】**纯猜想。

---

## 一、创世层

| 问题 | 主流推测 | 可信度 |
|---|---|---|
| **法涅斯现在在哪？** | 已在王座更替中消失/沉睡；「原初之人」可能已非人格存在 | 中 |
| **第二王座是谁？** | 有说法是后来的天理、也有说是「深渊」或外来者 | 低 |
| **四影的现状** | 时之执政伊斯塔露仍在暗中活动（蒙德、稻妻、坎瑞亚多处痕迹）；**6.x 第九、十幕中死之执政、时之执政、生之执政首次在主线正文现身**，默许纳西妲行使「毁灭世界树的最高权限」（空之执政未现身） | 高 |
| **天理是人格还是规则** | 更可能是一套「由法涅斯奠定、四影维护」的自动秩序 | 中 |
| **七龙王是否还有存活者** | 那维莱特（水）、阿佩普（草）、若陀（岩）为案例；其余龙王状态不明 | 高 |

## 四、月、挪德卡莱与须弥终局（第六章核心）

| 问题 | 主流推测 | 可信度 |
|---|---|---|
| **三月女神是谁** | 远古掌月的三位女神——**恒月艾莉亚／霜月卡侬／虹月桑娜妲**（名字取自音乐体裁），与「月之真相」和提瓦特的时间/命运体系相关 | 高 |
| **月亮为什么是「假的」** | 提瓦特天空上的月亮可能并非自然天体，而是某种构造/伪装 | 中 |
| **狂猎现象** | 与深渊、坎瑞亚罪人、月的残缺相关 | 中 |
| **月髓 / 虹月的月髓** | 月亮力量凝结的核心，与挪德卡莱的「月矩力」相关；仅三枚（**恒月月髓／虹月月髓／人造月髓**），三枚齐聚可掌持「生、死、时、空」 | 高 |
| **赤月所在的空间** | 与「三月」体系的缺失环节相关 | 中 |
| **尼可 / 艾莉丝 / 莱茵多特的关系** | 均为远古或超长期存在者，立场各异 | 中 |
| **哥伦比娅成为唯一「三月女神」的后续** | 她将霜月拖入虚假之天以锚定自身存在，并通过月亮倒影回到过去接过三月权能；**世界的排斥（「理」）是否因此解除**、三月权能集于一身是否违背三月旧约，均未明 | 中 |
| **第四个月亮「新月」与「天理维系者」是否同一** | 三月消失后新月升起、新月前坐着一位女性神灵；有考据认为她就是自称「天理维系者」的女神 | 低 |
| **火神之心为何消失** | 焚烧世界树七天七夜后，残骸中「连被化为灰烬的痕迹都没有」；玛薇卡仅称「可能也是某种命运的延展」 | — |
| **「阿如」取代世界树的后果** | 阿如成为新世界树、尼可将纳西妲与世界树的连结嫁接至阿如（其存在根基改与阿如绑定）；阿如的稳定性与「神体与他物同源」的风险未明 | 中 |

## 七、结构层：作品本身的问题

- **旅行者的最终目标**：找回血亲 / 理解世界的真相 / 或两者只能选一。
- **「一切将被重新编织」**：多次出现的预言式表述，指向某种世界级重置。
- **第三幕之后是什么**：至冬篇之后，是否还有第八章与结局篇。
- **七神体系的终点**：神座可以被摧毁（枫丹），那么七神体系是否会整体瓦解。

## 八、如何自行核对

建议优先查证来源：
1. **游戏内文本**：任务对话、书籍、石碑、角色故事、武器/圣遗物描述。
2. **官方渠道**：米游社、官方网站、版本前瞻直播、官方设定集。
3. **社区考据**：各语言 Wiki 的任务文本与道具描述交叉比对。
4. 遇到冲突时，**以游戏内最新剧情为准**。
