# 09 · 稻妻篇：雷与永恒

> **国家**：稻妻（Inazuma）　**元素**：雷（Electro）　**神明**：雷神巴尔泽布（雷电将军）
> **理念**：永恒　**原型**：日本（幕府、锁国、神社、妖怪、和风美学）

---

## 一、地域概况

稻妻是**群岛之国**，长期实行**锁国政策**，外人难以进入。地理上分为多个岛屿，各岛文化气质差异明显。

| 岛屿 | 说明 |
|---|---|
| **鸣神岛** | 稻妻主岛，稻妻城、天守阁、鸣神大社所在地 |
| **神无冢** | 战乱与祟神污染的废墟之岛，踏鞴砂炼铁厂 |
| **八酝岛** | 被「祟神」与结界影响的重灾区，雷灾之地 |
| **海祇岛** | 珊瑚宫心海领导的独立势力，信仰「海祇大御神」 |
| **鹤观岛** | 被迷雾封锁的岛，埋藏古代文明与「雾海纪行」真相 |
| **渊下宫** | 稻妻地下的古代文明遗迹，与「白夜国」和远古历史直接相关 |
| **清籁岛 / 天云峠** | 雷鸟与雷灾的源头 |

---

## 二、历史脉络

### 1. 远古：白夜国与渊下宫
- 稻妻地下曾存在高度发达的古代文明**白夜国**，其遗迹即**渊下宫**。
- 渊下宫的壁画、文献是理解**「第一王座 / 第二王座」**、远古人类与天空岛关系的关键证据。
- 渊下宫人与白夜国的灭亡，与「太阳」「龙」相关的远古叙事有关。

### 2. 魔神战争与雷神的双生
- 魔神战争时期，**雷电真**（巴尔，Baal）与**雷电影**（巴尔泽布，Beelzebul）是一对双生魔神姐妹。
- 雷电真成为初代雷神，主政；雷电影则是战士，擅长武艺。
- **五百年前的坎瑞亚灾变**中，雷电真在坎瑞亚战死。雷电影因此陷入对「失去」与「无常」的深刻恐惧。

### 3. 「永恒」的执念与「雷电将军」
- 雷电影为了对抗「无常」，追求**永恒**：
  - 制造替身人偶**「雷电将军」**代为执政；
  - 将自己的意识封入**「一心净土」**冥想；
  - 颁布**锁国令**与**眼狩令**，收缴神之眼，冻结变化。
- **眼狩令**引发巨大民怨，直接导致反抗军（海祇岛珊瑚宫一方）与幕府的战争。

### 4. 现代
- 三奉行（社奉行、勘定奉行、天领奉行）腐败，愚人众趁虚而入。
- 愚人众「女士」与「散兵」深度介入稻妻内政，是眼狩令与内战的重要推手。

### 5. 远古补遗：鹤观前文明与樱之庭
- **鹤观前文明**：鹤观的前文明信仰三月女神，并称她们为「**赫卡忒**」；用壁画与「**石根文字**」记录历史。天钉降下使鹤观天空被净化但被迷雾笼罩，其后文明覆灭，由鹤观后文明取代。可信度：【中】
- **樱之庭**：恒月破碎、海洋升起，远古**樱之庭**与其它岛屿的联系断绝。可信度：【中】
- **流沙无名古国**：愚王在万古流沙上梦想筑造供养银白古树的高庭。可信度：【中】
- **坎瑞亚使团窃书**：魔神战争期间、渊下宫整体迁往海面的最后一天，坎瑞亚向**白夜国**派遣的武装使团试图窃取白夜国图书馆禁书《**日月前事**》，被图书管理员**安贞**等人阻止；交战中一台耕地机因核心被取出、坐在馆藏上，没人能搬动。可信度：【高】

### 6. 奥罗巴斯、海祇岛与踏鞴砂
- **奥罗巴斯东迁**：魔神战争期间坠入海渊的魔神**奥罗巴斯**（Orobashi）将渊下宫（白夜国）之民带出海渊，建立**海祇岛**。为解决耕地不足，奥罗巴斯率海祇民入侵**八酝岛**；两方鏖战今八酝岛，幕府方大将**天狗笹百合**、海祇岛「**东山王**」、巫女「**曚云**」战死，曚云之妹「**海御前**」失踪。**雷电将军亲自赶来，以「无想的一刀」将其斩杀**，那一刀形成了如今的「**无想刃狭间**」。可信度：【高】
- **海祇大御神与踏鞴砂**：此后雷电将军准许已死的奥罗巴斯以「**海祇大御神**」之名受祭，海祇岛名义上接受鸣神幕府统治并修建鸣神分社；为消耗沾有魔神遗怨的「**晶化骨髓**」，幕府在**神无冢建立踏鞴砂**，用晶化骨髓锻造「**玉钢**」武器。可信度：【高】

### 7. 雷神传承、狐斋宫与御舆一族
- **狐斋宫履任**：**狐斋宫**离开白辰之野、赴任鸣神大社时，**八重神子尚未出生**；八重之游历生涯最后也以赴任鸣神大社作结，因血脉相亲，斋宫对年幼的八重照顾颇多。可信度：【高】
- **雷神双生的交棒**：**雷神雷电真（巴尔）在坎瑞亚战争中丧命**，弥留之际将稻妻、神之心、太刀「**梦想一心**」和雷神的位置交给一直以来作为她影武者的双生魔神**雷电影（巴尔泽布）**。可信度：【高】
- **有乐斋与狐斋宫的三次离去**：此前**有乐斋**犯下大罪引得斋宫震怒、引咎离去（至今已有五百余年），**狐斋宫**便不再驻留鸣神大社而前往城中天守长居（「天变地异之浩劫将至……因此尽快前往将军身侧才行」，这是她第二次离去，八重神子已是少女之龄）。不多时灾厄席卷列岛，**狐斋宫第三次离去，也是永远地离开了（身死）**。从坎瑞亚归来的**巴尔泽布借助了神樱树的力量，凭无想的一刀肃清了稻妻本土的灾厄**。可信度：【高】
- **御舆一族**：在漆黑灾厄中被魔兽吞噬又破体而出的**御舆千代**因被深渊力量侵染而发疯、向雷电将军举刀，被击败逃跑；她的嫡子**御舆道启**接受天狗**影向光代**的指导，改姓**岩藏**，创立**岩藏流**；养子**御舆长正**为洗清家族污名加入幕府。可信度：【高】
- **惟神晴之介与五百藏**：**狐斋宫身死后，惟神晴之介前往璃月修习仙术**，后返回稻妻创立**阴阳术**、成为阴阳师；在一次神樱大祓中因镇物被偷，他将偷走镇物的妖狸**五百藏**全族封印；此后创立**诀箓阴阳寮**，用阴阳术和式神训练有志的人类武士，借此消灭稻妻大地上的妖恶——可这一行动因雷电将军先一步消灭了妖物而变得毫无意义，此后惟神晴之介不知所踪。可信度：【高】

### 8. 五百年前后的踏鞴砂与稻妻之变
- **踏鞴砂事故（约 400 余年前）**：踏鞴砂炉心发生故障，时任造兵司正**丹羽**携家眷潜逃；事件平息后，御舆长正的寄骑**桂木**作为责任人被斩杀。可信度：【高】
- **人偶技术的来源**：**雷电影创造的人偶**，其技术来自**坎瑞亚机械工程学**，由**地脉树枝**打造。可信度：【高】
- **雷电五传断绝**：稻妻的雷电五传逐渐断绝，仅余**天目流**；**枫原家、神里家受重创**。可信度：【中】
- **恒常机关阵列与遗迹机兵**：盘桓遗迹的不祥机械生物（恒常机关阵列、遗迹机兵）藏匿在稻妻列岛——这些遗迹与五百年前的大灾难有关，那场大灾据说不论海陆都没有幸免深渊的侵袭。可信度：【中】
- **御影炉心**：前几年，为扩大生产规模，幕府从枫丹请了一支顾问团队，建造了能充分利用「祟神」力量的「**御影炉心**」——以枫丹技术建造、以八酝岛运来的「祟神」核心驱动的超级冶炼炉。可信度：【高】

## 三、主要势力

| 势力 | 核心人物 | 说明 |
|---|---|---|
| **幕府 / 天守阁** | 雷电将军、九条裟罗、三奉行 | 稻妻的统治机构 |
| **鸣神大社** | 八重神子 | 神社与神道体系，八重是雷电影的旧友 |
| **社奉行神里家** | 神里绫人、神里绫华 | 三奉行之一，主角的主要盟友 |
| **海祇岛 / 珊瑚宫** | 珊瑚宫心海、五郎 | 反抗军核心，信仰海祇大御神 |
| **愚人众** | 「女士」、**「散兵」**（国崩） | 散兵曾是雷电影制造的原型人偶，被弃置 |
| **其他** | 枫原万叶、宵宫、荒泷一斗、久岐忍、托马、早柚 | 万叶是稻妻流浪武士，与友人之死相关 |

**关键人物补充**：
- **散兵 / 流浪者**：雷电影为「永恒」制造的原型人偶，因被认为「有情感」而被弃置。后被愚人众收养，成为执行官第六席「散兵」。在须弥主线中被击败、抹除记忆，重生为「流浪者」。**他身上藏有关于坎瑞亚与世界真相的重要信息**。
- **八重神子**：鸣神大社宫司，狐狸形态的雷神眷属，长期在暗中布局。

## 四、主线剧情（第二章）

1. **第一幕「不动鸣神，恒常乐土」**
   - 旅行者抵达稻妻，见识锁国与眼狩令下的压抑社会。
   - 与神里绫华结盟，接触被收缴神之眼者的苦难。
   - 与雷电将军正面交锋，**旅行者被一刀击败**——这是全作中旅行者最惨痛的一次挫败。

2. **第二幕「无念无想，泡影断灭」**
   - 旅行者前往海祇岛，与珊瑚宫心海、反抗军结盟。
   - 参与反抗军与幕府的战争，逐渐触及雷电将军「永恒」理念的真相。

3. **第三幕「千手百眼，天下人间」**
   - 愚人众与「女士」的阴谋暴露。
   - 旅行者借助**「愿力」**（民众的愿望）再次挑战雷电将军，进入「一心净土」。
   - 在八重神子、万叶等人协助下，旅行者说服雷电影……但更关键的是**「雷电将军」人偶被击败后，雷电影本人才真正现身**。
   - 雷电影废除眼狩令，稻妻重新开放。
   - **八重神子以「旅行者」的名义从雷电影手中取走神之心**（实际上交给愚人众以避免更大麻烦）——这是全作中处理得最「圆滑」的一颗神之心。

4. **后续：传说任务与其他**
   - **雷电将军传说任务「天下人之章」**：揭示雷电影对「永恒」理解的转变。
   - **渊下宫 / 白夜国**：支线中给出远古历史的核心碎片。
   - **层岩巨渊、鹤观、清籁**等区域故事补充古代文明线索。

## 五、稻妻的世界观意义

- **永恒 vs 变化**：稻妻的主题是「为了不变而付出的代价」，与蒙德的「自由」、璃月的「契约」并列为三种治理哲学。
- **神的心理创伤**：雷电影是第一位被明确刻画为「因创伤而做出错误政策」的神明。
- **人偶与造物**：雷电将军人偶、散兵，与坎瑞亚的「人造生命」主题相通。
- **神之心的第三次易手**：稻妻篇给出了「神之心并非神明的全部」这一概念，为须弥、枫丹的进一步揭示铺路。
- **渊下宫与白夜国**：为整个提瓦特远古史（第一王座、第二王座、龙、天理）提供了最直接的地下档案。
