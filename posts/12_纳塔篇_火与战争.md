# 12 · 纳塔篇：火与战争

> **国家**：纳塔（Natlan）　**元素**：火（Pyro）　**神明**：火神玛薇卡（Mavuika）
> **理念**：战争　**原型**：中南美洲（阿兹特克、玛雅、安第斯）+ 非洲 + 波利尼西亚，混合部落联盟气质

---

## 一、地域概况

纳塔是**六部族共治**的战争之国，长期与**深渊**处于战争状态。地形包含火山、草原、峡谷、温泉、丛林与古代遗迹。

| 地点 | 说明 |
|---|---|
| **圣火竞技场 / 归火之地** | 纳塔的核心仪式场所，「归火圣夜巡礼」的举办地 |
| **夜神之国** | 死者灵魂的归处，纳塔人信仰中的冥界 |
| **回声之子**（Children of Echoes） | 部族之一，与矿石、火山相关 |
| **流泉之众**（People of the Springs） | 部族之一，温泉与水的部族 |
| **花羽会**（Flower-Feather Clan） | 部族之一，与飞禽、空战相关 |
| **悬木人**（Masters of the Night-Wind） | 部族之一，与夜风、萨满传统相关 |
| **沃陆之邦**（Collective of Plenty） | 部族之一，与丰收、农业相关 |
| **第六部族** | 与烟、雾、谜团相关的部族（名称以游戏内为准） |

> 六部族的正式名称以游戏内文本为准；上表为通行译名。各部落并非简单的地域划分，而是**六种对抗深渊的传统与技艺**。

---

## 二、核心设定

### 1. 龙（Saurians）
- 纳塔人与**龙**共生。龙可以变形为**交通工具**（如滑翔、奔跑、游泳形态），这是纳塔独有的「龙骑」系统。
- 龙与纳塔的「古龙大权」传统相关，是「龙与七神」主线的重要一环。

### 2. 夜神之国与「不被遗忘」
- 纳塔人相信死者会进入**夜神之国**。
- 纳塔的核心文化母题是**「记忆与传承」**：只要还有人记得，英雄就不会真正死去。
- **「归火圣夜巡礼」**等仪式，本质是把英雄的名字与事迹刻入部族记忆。

### 3. 深渊战争
- 深渊在纳塔的侵蚀远比其他七国严重，表现为「深邃之隙」与生物异化。
- 纳塔的「战争」理念并非侵略，而是**世代抗深渊的生存战争**。

### 4. 火神玛薇卡
- 玛薇卡（Mavuika）是当代火神，但她**来自五百年前的坎瑞亚灾变时期**。
- 为了在正确的时机迎战深渊，她跨越时间来到现代。
- 她与初代火神**希巴拉克**（Xbalanque）有直接关联。
- 玛薇卡的最终计划涉及**以自身为「燃愿」**，即牺牲自己来点燃对抗深渊的力量。

## 三、历史脉络

| 时期 | 事件 |
|---|---|
| 远古 | 初代火神希巴拉克时代；纳塔确立六部族与「战争」传统 |
| 远古 | 与深渊的战争开始，形成「巡礼」与「英雄记忆」制度 |
| 约 500 年前 | 坎瑞亚灾变；深渊大举侵攻纳塔 |
| 约 500 年前 | 玛薇卡为未来的决战做准备，跨越时间来到现代 |
| 现代 | 纳塔主线：六英雄集结 → 对抗深渊 → 玛薇卡牺牲与回归 |

### 5. 五百年前：坎瑞亚小队与「天柱骑士」瑟雷恩
- **「天柱骑士」瑟雷恩**拥有机械制的心脏，被列名为**天柱骑士**（由「列名」可知不止一人）。他率一批坎瑞亚小队且战且退来到**纳塔**，见证战役带来的巨大牺牲与深渊带来的恐惧绝望；在纳塔结识当时**烟谜主首领阿伊祖**，学会烟谜主法术（能将外溢的灵魂送回地脉），并从阿伊祖口中得知**火神之心的用法**。可信度：【高】
- **渊蚀综合症与清幻剂**：因深渊影响，小队员罹患「**渊蚀综合症**」陷入幻觉与疯狂甚至自相残杀；副官**古瑟雷德**把自己当实验体研发能克制病症的**清幻剂**，因此牺牲。可信度：【高】
- **机械心脏与不死诅咒**：因夜神之国遭破坏、逝者灵魂无家可归，瑟雷恩**将逝去人们的灵魂容纳在自己的机械心脏内**，五百年来日复一日承受体内灵魂的哀鸣，导致其从未入眠。他被降下不死诅咒，肉体在漫长时间中腐烂于是戴上面具。**他就是后来的愚人众第一席「队长」卡皮塔诺。** 可信度：【高】
- **西弗安雅与伊利萨**：两位坎瑞亚战士与当时「回声之子」长老**陶奥鲁**缔结深厚友谊，牺牲自己帮助纳塔英雄封印深渊力量，两人却和深渊魔物一同被封印，从此在封印里陷入永远的战斗无法解脱，但仍和其他被封印的纳塔人／龙的意识一起阻止深渊涌出「镌光铭印」，却被后人误解为引来深渊的人。可信度：【中】

### 6. 玛薇卡的圣火计划与地脉危机
- 由于地脉结构不像其他国家那么强韧，**纳塔成为深渊入侵时地脉受损最严重的国家**，等同于纳塔地脉的「**夜神之国**」遭到深渊侵蚀，深渊开始对纳塔六大部族进行针对性破坏。可信度：【高】
- **火神玛薇卡与六英雄预见到 500 年后纳塔将因深渊灾厄而毁灭**，因此制定长远计划：玛薇卡与亲人朋友道别后，**将自己的生命存入圣火并因此提前死去**，以期能在 500 年后复活继续帮助纳塔人。纳塔人花费许多年终于逐步消除了深渊对纳塔的破坏。可信度：【高】
- 「**古名**」不会记录纳塔之外的经历，也就不会被记录到夜神之国中；无法得到大灵承认的记忆与经历，就无法成为「古名」的材料。可信度：【高】
- **「队长」的结局（补充）**：玛薇卡与六英杰动用**若娜瓦**（死之执政）的力量暂时击败深渊本体古斯托特后，必须履行契约、向死之执政支付生命作为代价；**「队长」代替了玛薇卡**，坐上「**源火之圣座**」，如愿与夜神融为一体，使夜神得以不死，并**改变了夜神之国的规则，使其可容纳纳塔人以外人的灵魂**，由此使自己在坎瑞亚的众多部下的灵魂拥有归宿，并以此作为向对他降下不死诅咒的死之执政的复仇。女皇保留了他的第一席席位。可信度：【高】

### 7. 近代：烬寂海异变
- 约二三十年前，有人在**烬寂海**目击到一个黑色山岳般的巨物在其中移动，不久后，**整个烬寂海突然消失**。可信度：【中】

### 8. 存疑：纳塔火神世代谱系
- 纳塔火神世代谱系一说为：希巴拉克 → 「赤瞳少年」 → 库穆库尔／恩德盖 → 玛薇卡 → 柯夏尼娜／古洛哈莉／修洛维兹 → 伊莎佳 → 玛薇卡（复活）。**属社区拼合，存疑。** 可信度：【存疑】

## 四、主要势力与人物

| 势力 | 核心人物 | 说明 |
|---|---|---|
| **火神阵营** | 玛薇卡 | 纳塔的核心领袖 |
| **六部族 / 六英雄** | 恰斯卡、茜特菈莉、希诺宁、基尼奇、玛拉妮、卡齐娜等 | 各自代表一部族的英雄 |
| **愚人众 · 队长** | **卡皮塔诺**（Il Capitano，执行官第一席「队长」） | 纳塔线关键人物，与玛薇卡有宿缘 |
| **愚人众 · 其他** | 达达利亚（公子）、潘塔罗涅（富人）、多托雷（博士） | 在纳塔/周边活动中出现 |
| **其他** | 欧洛伦、伊安珊、瓦蕾莎、玛拉妮 | 纳塔本地可玩角色 |

**关键人物补充**：
- **「队长」卡皮塔诺**：愚人众第一席，被誉为最强的战士之一。在纳塔主线中，他与玛薇卡共同对抗深渊，最终**牺牲自己**——这是愚人众阵营中第一位以「英雄式牺牲」离场的执行官。
- **六英雄**：纳塔对抗深渊的关键，其实质是「六部族记忆的具现」。

## 五、主线剧情（第五章）叙事流程

1. **抵达纳塔**：旅行者进入这个与深渊世代交战的国家，参与「归火圣夜巡礼」，结识各部族。
2. **六英雄集结**：随着深渊侵蚀加剧，六部族的英雄逐一登场并完成各自的成长。
3. **愚人众的介入**：「队长」卡皮塔诺到来，其目的与纳塔的存亡部分重叠，形成「亦敌亦友」。
4. **决战深渊**：纳塔与深渊的战争进入最终阶段，玛薇卡启动 **「燃愿」计划**——以自身为燃料点燃圣火。
5. **牺牲与回归**：玛薇卡与「队长」先后付出巨大代价。纳塔人通过**记忆与传承**（全作对「不被遗忘」最直接的一次表达）把英雄「带回来」。
6. **结局**：深渊被击退，纳塔的部族传统得到确认，火神与纳塔的关系进入新阶段。

## 六、纳塔的世界观意义

- **「战争」不等于侵略**：纳塔把「战争」诠释为对外的生存防御与对内的荣誉制度。
- **记忆即力量**：纳塔是唯一把「被记住」当作实质力量体系的国家。
- **龙与人共生**：纳塔提供了「龙不是敌人而是伙伴」的样本，与璃月封印若陀、枫丹龙王掌权形成对照。
- **愚人众的复杂性**：「队长」的牺牲打破了「愚人众 = 纯反派」的简化叙事。
- **时间与献祭**：玛薇卡跨越五百年的设定，把坎瑞亚灾变的余波直接接到现代主线。
