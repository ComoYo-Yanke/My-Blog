# 07 · 蒙德篇：风与自由

> **国家**：蒙德（Mondstadt）　**元素**：风（Anemo）　**神明**：风神巴巴托斯
> **理念**：自由　**原型**：中世纪德意志 / 低地国家（城市与酒馆、骑士团、教会）

---

## 一、地域概况

蒙德位于提瓦特大陆的**北部偏西**，地势以丘陵、平原、湖泽为主，气候温和，长年有西风穿过。

| 地点 | 说明 |
|---|---|
| **蒙德城** | 建在果酒湖中央的岛屿城市，四周环水，靠桥与陆地相连 |
| **风起地** | 巨大的橡树，据说是风神力量的残留，骑士团誓约之地 |
| **奔狼领** | 北风狼王安德留斯的领域，狼群与「北风的狼王」传说 |
| **风龙废墟** | 曾是旧蒙德「高塔孤王」的领地，现为魔物与遗迹所在 |
| **望风山地 / 明冠峡 / 誓言岬 / 达达乌帕谷 / 清泉镇 / 晨曦酒庄** | 蒙德周边聚落与地标 |
| **龙脊雪山** | 毗邻蒙德的永冻之山，埋藏着被毁灭的古国「雪葬之都·沙尔·芬德尼尔」 |

---

## 二、历史脉络

### 1. 远古：龙脊雪山的古国（沙尔·芬德尼尔）
- 龙脊雪山原本并非雪山，山上有过繁荣的古国**沙尔·芬德尼尔**（Sal Vindagnyr）。
- 该国因触怒天空岛（或招致了某种「天罚」），天空降下**「寒天之钉」**，将整座山钉入永冬。
- 雪山的遗迹、壁画、祭坛至今仍保存着这段历史，是理解「天理如何惩罚人类」的重要样本。

### 2. 魔神战争：高塔孤王与风神的诞生
- 魔神战争时期，蒙德一带由魔神**「高塔孤王」迭卡拉庇安**（Decarabian）统治。他用**风墙**把人民围在旧蒙德城内，名义上是保护，实质是囚禁。
- 另一位魔神**「北风狼王」安德留斯**（Andrius）与迭卡拉庇安争战，两者僵持。
- 一名**无名少年**（温迪的挚友）带领人民反抗高塔孤王；与少年同行的**风精灵**（温迪的前身）最终帮助人民推翻暴君。
- 少年在反抗中战死。风精灵因此获得神格，成为新的风神**巴巴托斯**，吹散风墙与风雪，蒙德成为**自由之城**。
- 安德留斯放弃了对蒙德的争夺，将自己的力量归还大地，成为奔狼领的守护者。

### 3. 贵族时代与温妮莎起义
- 巴巴托斯离开/沉睡后，蒙德由**贵族**统治。以**劳伦斯家族**为首的贵族逐渐腐化，压迫平民。
- 红发女战士**温妮莎**（Vennessa）——来自「穆纳塔」（纳塔的古称）的族人——领导奴隶与平民起义，推翻贵族统治。
- 温妮莎确立了**西风骑士团**的体制，成为「狮牙骑士」，蒙德进入骑士团与教会共治的时代。
- 温妮莎最终被天空岛接引（飞升），这是「人类可以升入天空岛」的重要实例。

### 4. 五百年前：坎瑞亚灾变与魔龙杜林
- 坎瑞亚覆灭引发全提瓦特的灾难，深渊魔物大规模入侵。
- 坎瑞亚「黄金」**莱茵多特**创造的魔龙**杜林**（Durin）袭击蒙德。
- **风龙特瓦林**（Dvalin，东风守护）与巴巴托斯联手击杀了杜林，但特瓦林被杜林的毒血与深渊污染长期腐蚀。
- 这段历史直接造成序章的风魔龙事件。

### 5. 现代
- 西风骑士团**大团长法尔伽**率主力远征在外（远离蒙德），城内由**代理团长琴**主持大局。
- 愚人众以「外交使节团」名义在蒙德活动，通过北国银行与政治压力渗透。
- 巴巴托斯（温迪）以吟游诗人身份在蒙德游荡，极少以神明身份出现。

### 6. 旧蒙德补遗：龙卷的魔神与风神的初生（约 3000～2600 年前）
- 上古时代的蒙德北境本是**冰原**。「高塔孤王」**迭卡拉庇安**（Decarabian）的真身是「**龙卷的魔神**」。可信度：【高】
- 约 3000 年前，是**迭卡拉庇安**与「北风之王」**安德留斯**（Andrius）混战的时代。彼时蛮荒的蒙德冰原上，**古恩希尔德**是流民中最强大的部族首领；其部族遗胤可上溯「第一文明」时代的分支**阿卡狄亚**。可信度：【高】／阿卡狄亚一系为【中】
- 约 2600 年前，旧蒙德城被飓风团团包围，连飞鸟也不得通行；风无休止，将城中土地与岩石磨成细腻如水的尘沙。高塔之上的风之君王迭卡拉庇安睥睨在无尽吹息中躬身臣民，认为他们顺服而十分满意。可信度：【高】
- **温迪的出身**：此时的温迪本是北境大地咆哮千风中的一缕，是「**能够带来细小的转机与希望之风**」的**元素精灵**，**当时并无魔神之格**。可信度：【高】
- **弹琴的少年**：温迪结识了一位懂得弹琴、渴望写出最好的诗、却**从未目睹飞鸟**的少年；为了他，温迪搜集来鹰隼的翎羽。可信度：【高】
- **红发的战士**：另有一名红发战士，以「**风之花**」传递暗语，在黎明前漫长的暗夜中编织晨曦（其名已湮没）。可信度：【高】
- **自由之战**：龙脊雪山的国度**沙尔·芬德尼尔**（聆听天空岛启示的国度）被天降之柱覆灭后，异邦勇士**伊蒙洛卡**离开荒废的雪山国都加入蒙德的战争，成为**新蒙德建立时三大家族之一**（古恩希尔德家族、劳伦斯家族、伊蒙洛卡家族）。**阿莫斯**同无名的少年、无名的精灵、无名的骑士一同登上如剑刺向深空的尖塔，挑战风中的乖僻王者。当巴巴托斯向无心的孤王发起挑战时，**古恩希尔德率领族人直面神的震怒**。可信度：【高】
- **巴巴托斯的诞生**：旧的神座崩毁、新神诞生。巴巴托斯体会到指尖流淌的力量，第一件事便是**以少年的模样重塑自身形体**（因为只有人类的形体才能弹好少年钟爱的竖琴）。他拂动琴弦，用神风吹散冰雪、劈开山峦，让新的蒙德成为自由之地、无人称王的国度——是为「**新蒙德**」之肇始。古恩希尔德为初生的风神**戴上桂冠**。可信度：【高】
- **安德留斯的离去**：新蒙德建立后不久，北风的狼王安德留斯**离开蒙德地区开始流浪**。可信度：【高】
- **特瓦林诞生（约 2600～1000 年前）**：挟带风元素的龙在高天诞生，缓缓降下、对世间一切充满好奇。他落在村落被恐惧的人们扔石头，落在墓园只听到悲伤嗟叹，落在果园被愤怒者咒骂——龙听不懂人们恐惧、悲伤与愤怒中说出来的话。人世太过纷繁复杂，龙迷惑了，但还是想尝试……可信度：【高】
- **第一文明时期的蒙德分支**：苍绿雪山时期的**沙尔·芬德尼尔**由法鲁希率族建立王城，居民信仰天空岛并与神使沟通；**塞西莉亚古国**与古树并存，在苍风高地建塞西莉亚苗圃、在摘星崖与千风神殿一带建「祝圣祭坛·夏宫灵囿」，后疑似天钉之物（原文写作「晨星」）落在坠星山谷的**星落湖**，古国此后覆灭——塞西莉亚花仅剩摘星崖还有，夏宫灵囿深埋地底成为「**仲夏庭园**」。可信度：【中】

### 7. 建国后至贵族时代补遗（约 2000～1000 年前）
- **七神酒会**：约两千年前魔神战争终结、七神就位后，巴巴托斯抚着竖琴消失在远方荒野（找帝君喝酒去了）。他初临璃月时，岩王帝君本以为同僚履职遇困、准备倾力相助，风神却递上一瓶蒙德城的酒。此后那个时代的**七神往往会在璃月相聚**。可信度：【高】
- **贵族暴政的开始**：建城一千六百年后、距今约一千年前，蒙德的「自由」陷入前所未有的恐怖低谷。巴巴托斯**因不愿成为暴君而离去**，从未想到受赠自由的人们竟自行造出了属「人」的暴君。贵族残暴统治蒙德，**将奴隶制带入这片土地**，全然无视受压迫者的呼喊。可信度：【高】
- **冒险家莱纳德**：约两千年前，冒险家**莱纳德**毕生梦想登上一座名叫「**尖帽子峰**」的雪山，恐惧于「它是一头没有弱点的凶兽」；放弃登山后将余生用于研究，留下「**未完成的羽翼**」设计图。两千年后，他的「**命之座**」化为陨石被某种原由召唤到大地上（即 1.1 活动「未归的熄星」）。可信度：【高】

### 8. 千年前的自由之战：人物与细节补遗（约 1000 年前）
- **帕西法尔**：与胞弟厄伯哈特同为反抗旧贵族制度的贵族子弟，忤逆长辈，偷窃家中弓与剑离家成为蒙德侠盗；后与追杀他的「魔女」相爱，因爱而不得，埋下长剑出海远航。可信度：【中】
- **厄伯哈特**：兰德里希家族成员、**私生子**，试图夺取族长之位、推翻劳伦斯家族；将优秀剑斗奴收为己用（此人在与温妮莎的对决中身死），私下修习枪法，挑唆帕西法尔离家成为侠盗，并组织前往龙脊雪山的探险队；探险中将其余人尽数重伤或杀害，据蒙德正史其行动似乎失败。可信度：【中】
- **流浪乐团（剑乐团）**：一支乐器兼作兵刃的乐队，伺机刺杀劳伦斯家族失败。成员包括用笛剑舞剑奏乐的女剑士、用钟剑打节拍、名为**克留兹里德**的前劳伦斯家成员、用琴弦放箭的枫丹琴师。起事后或死或逃，乐器被摧毁失去奏乐功能。可信度：【中】
- **莱艮芬德（晨曦骑士）**：曾作为侍从骑士为劳伦斯家族效力，在见证流浪乐团起事失败、被押为角斗奴的舞剑女子最后的战斗后，决定了自己的骑士名与目标。「**在重压之下、不得不奋起时才绽放**」——这一族宿命是**身居至暗的黑夜，带来破晓的火光**。可信度：【中】
- **北风骑士与王狼玻瑞亚斯**：与温妮莎革命同期，北风骑士自**挪德卡莱**流浪归来，随行的王狼**玻瑞亚斯**仅余残魂，最终理解人的世界，将灵魂汇入大地守护一方；北风骑士用剑作狼的坟冢将其葬于荒野，再度离开、不知所终。可信度：【中】
- **温妮莎的细节**：她是离开祖国的**纳塔人**，与族人在荒原流浪后全族进入蒙德、沦为**角斗奴**；剑术高超，角斗奴时期被称为「**红发的死神**」。千年前她在巴巴托斯协助下与族人**战胜魔龙乌撒**，并在其后的革命中从贵族**劳伦斯家族**手上夺取蒙德统治权，获封「**狮牙骑士**」／「**蒲公英骑士**」，**其后组建西风骑士团**，在**风起地手植树下辞世**，**死后升入天空岛**。巴巴托斯用弹琴唱歌协助东风之龙**特瓦林**大规模改造蒙德区域的地形和气候，削平崎岖地形、吹散冰雪、引来温暖潮湿的海风。可信度：【高】
- **「背风的密约」**：革命中令贵族手下诸多士兵倒戈的是一份「背风的密约」——内容是一场叛国交易：高层贵族背弃风，把蒙德的一切卖给邻国岩神；密约末尾刻着一道非神明不可为之的神圣符印「岩王帝君」。事实上那是**温迪为戏弄岩神练的一手假签名**；他始终无法当面骗过那位财富与交易之神，屠龙之技无处可施，终于在几百年后找到活用的机会。可信度：【高】

### 9. 五百年前：杜林之役的相关人物补遗
- 灾厄席卷蒙德，毒龙**杜林**袭击蒙德城；**鲁斯坦**死于与魔物的战斗。受蒙德民众祈愿的召唤，**巴巴托斯归来**，唤回风龙特瓦林并与它一同与杜林战斗，将其击杀于龙脊雪山；但特瓦林被杜林的毒血浸染，在旧蒙德废墟沉睡。可信度：【高】
- **罗莎琳**：得知恋人鲁斯坦死讯后，自须弥教令院求学归来的蒙德少女**罗莎琳**化为**炎之魔女**，发誓烧尽世间一切魔物。可信度：【高】
- **纯白骑士罗兰**：鲁斯坦的弟子**纯白骑士罗兰**深入覆灭的古国坎瑞亚；在世界之底他明白了古国终末魔物起源的故事、发现了至大的不公，**效忠深渊**（「伟大的古国被降下了不义的惩罚……」）。可信度：【高】
- **「光之狮」艾伦德林**：因挚友鲁斯坦战死而伤痛过度，卸下西风骑士团大团长一职（狮牙骑士传承因无人持有资格而空缺）。可信度：【高】
- **杜林的结局（补充）**：杜林听闻风之歌者的琴声前往蒙德，以为自己在与人们共舞，实则造成无法挽回的灾厄；最终它在白雪之中看着风之歌者指引蓝宝石般的龙将利牙刺入自己喉咙。它长眠于龙脊雪山，吞下漆黑之血的特瓦林陷入沉睡；古树吸收了杜林的漆黑之血、继承了它的意志。魔女M因不满杜林的结局而在童话故事中创造小杜林。可信度：【高】
- **黄金王兽**：坎瑞亚覆灭后，黄金王兽曾引领黑狼之群攻击**奔狼领**，被北风之狼击败后逃至**鹤观**，只有数只兽境幼兽仍蛰伏该处，撕裂世界空隙以打开从鹤观通往奔狼领的通道。可信度：【高】

### 10. 近代：莱艮芬德家与骑士团
- 约十几年前，**凯亚·亚尔伯里奇**被**克利普斯·莱艮芬德**收养；其父（深渊教团创始者克洛达尔·亚尔伯里奇的后人）为「某个古老的阴谋」将其子抛弃在蒙德，让他成为坎瑞亚安插在蒙德的间谍——「这是你的机会，你是我们最后的希望」。可信度：【高】
- 四年前，**克利普斯·莱艮芬德使用邪眼击退魔龙乌撒后死亡**，迪卢克与督察长伊洛克发生口角后**抛弃神之眼、退出西风骑士团**、游历七国。同年**安柏的祖父不辞而别**，西风骑士团侦察小队名存实亡。可信度：【高】
- 三年前，**可莉**被身为知名冒险家的父母托付给西风骑士团，与阿贝多一起与蒙德的「家人们」结下缘分。可信度：【高】
- 一年前，迪卢克在孤独游历持续三年后回到蒙德城，接下家族产业成为「晨曦酒庄」新任庄主；愚人众执行官**博士**造访蒙德，蒙德城发生**黑火案**。可信度：【高】
- 半年前，**法尔伽**率领西风骑士中的精锐再一次离开蒙德，踏上远征之路。可信度：【高】

## 三、主要势力

| 势力 | 核心人物 | 说明 |
|---|---|---|
| **西风骑士团** | 大团长法尔伽、代理团长琴、丽莎、凯亚、阿贝多、安柏、优菈、诺艾尔、米卡、罗莎莉亚 | 蒙德的军事与行政管理机构 |
| **西风教会** | 芭芭拉 | 信仰风神的宗教组织，与骑士团共治 |
| **酒庄与酒馆** | 迪卢克（晨曦酒庄 / 天使的馈赠）、迪奥娜（猫尾酒馆） | 蒙德的经济与情报中心，「酒」是蒙德的文化核心 |
| **冒险家协会** | 凯瑟琳 | 全提瓦特连锁组织，蒙德设有分会 |
| **愚人众** | 使节、北国银行 | 以合法身份在蒙德活动 |

**关键人物补充**：
- **阿贝多**：莱茵多特的学生/造物，白垩之子，蒙德的首席炼金术士，其存在与坎瑞亚、杜林密切相关。
- **凯亚·亚尔伯里奇**：姓氏指向坎瑞亚，身份是重要伏笔。
- **迪卢克**：曾为骑士，退出后以私人身份对抗愚人众与深渊教团。

---

## 四、主线剧情（序章）

序章发生在蒙德，是旅行者（荧/空）与派蒙旅程的**起点**。

1. **抵达与风魔龙**：旅行者来到蒙德，正逢风魔龙特瓦林袭击城市。与安柏、凯亚、丽莎结识，加入西风骑士团协助调查。
2. **真相与净化**：追查发现特瓦林是被深渊教团（及其背后的扭曲力量）影响，才攻击蒙德。温迪以「天空之琴」试图安抚/净化特瓦林；琴一度被破坏或失窃，需要夺回。
3. **风魔龙之战的解决**：旅行者与温迪、特瓦林共同解决危机，特瓦林重获清明。
4. **愚人众的登场**：愚人众在此过程中暴露真实意图。**愚人众执行官「女士」出手夺取了温迪（巴巴托斯）的神之心**，这是全游戏中第一次展示「神之心被抢」这一主线的核心机制。

> 序章奠定了整个游戏的基本模式：旅行者每到一国，都会遇到「当地的危机 + 愚人众的插手 + 神之心的得失」。

## 六、蒙德的世界观意义

蒙德是整部作品的**「入门教科书」**：
- **自由**：蒙德的主题是「不设墙的自由」，与稻妻的「永恒之锁」形成对照。
- **神明的缺席**：巴巴托斯是最「不干涉」的神，蒙德因此最像「人类自己治理的国家」。
- **愚人众模式**：序章演示了愚人众如何用「合法外衣 + 关键抢夺」推进计划。
- **第一颗神之心**：从这里开始，「七颗神之心」成为贯穿全作的主线麦高芬。
