# 蓝桥杯算法试题与解析

> 挑了四道有代表性的蓝桥杯真题：两道填空、两道编程。每题都从「怎么想到」讲到「怎么写」，中间配图解。

## 一、先说赛制

蓝桥杯的题分两类，做法完全不一样：

| 题型 | 交什么 | 策略 |
| --- | --- | --- |
| 填空题 | 只交一个答案 | 暴力枚举、手算、写个脚本跑一遍就行，不用管复杂度 |
| 编程题 | 交代码，按测试点给分 | 注意读入格式和边界，拿部分分也比拿 0 分好 |

省赛常考的那几类其实很集中：递推 / 枚举、二分答案、DFS / BFS、动态规划、简单数论。下面四题正好覆盖前三类。

---

## 二、生日蜡烛（2016 · C/C++ B 组 · 填空）

> 某君从某年开始每年都办一次生日 party，每次都要吹熄与年龄相同根数的蜡烛。现在算起来，他一共吹熄了 236 根蜡烛。请问，他从多少岁开始过生日的？

![](posts/assets/lanqiao-candles.svg)

这题的关键不是算法，是**把题目翻译成式子**：假设从 `start` 岁开始，一直过到 `end` 岁，那么总数就是

```
start + (start+1) + (start+2) + ... + end = 236
```

两个未知数，但 `start` 的范围很小，直接枚举。

```cpp
#include <cstdio>

int main() {
    for (int start = 1; start <= 100; ++start) {
        int sum = 0;
        for (int age = start; age <= 100; ++age) {
            sum += age;
            if (sum == 236) { printf("%d\n", start); return 0; }
            if (sum > 236) break;   // 再加只会更大，提前退出
        }
    }
    return 0;
}
```

输出 `26`。

如果不想写代码，用等差数列也能算：8 项之和 236，平均每项 29.5，中间两项是 29 和 30，所以是 **26 到 33**。

> **考点**：枚举的顺序和终止条件。`sum > 236` 那句 `break` 是性价比最高的优化——没它也能过，有它能省一大半时间。

## 三、煤球数目（2016 · C/C++ B 组 · 填空）

> 有一堆煤球，堆成三角棱锥形。第一层 1 个，第二层 3 个，第三层 6 个，第四层 10 个……如果一共 100 层，共有多少个煤球？

![](posts/assets/lanqiao-coal.svg)

第 n 层的煤球数是 `n(n+1)/2`，也就是前 n 个自然数之和。但更快想到的写法是看**相邻两层的差**：

```
第 2 层 - 第 1 层 = 2
第 3 层 - 第 2 层 = 3
第 4 层 - 第 3 层 = 4
```

每层比上一层多 n 个。所以一边累加总数，一边更新当前层数就行，连乘法都不用。

```cpp
#include <cstdio>

int main() {
    int layer = 1;      // 当前这一层的煤球数
    int total = 0;
    for (int i = 1; i <= 100; ++i) {
        total += layer;     // 先加上这一层
        layer += i + 1;     // 下一层比这一层多 i+1 个
    }
    printf("%d\n", total);
    return 0;
}
```

输出 `171700`。

手算验证一下：`S = Σ n(n+1)/2 = 1/2 (Σn² + Σn)`，代入 n = 100 得 `1/2 (338350 + 5050) = 171700`，对上了。

> **考点**：找递推关系。这类题的套路是「先写前四项，看看相邻两项差什么规律」，比硬推公式快得多。

## 四、分巧克力（2017 · C/C++ B 组 · 编程）

> 有 K 位小朋友，小明有 N 块巧克力，第 i 块是 `H_i × W_i` 的长方形。要从这些巧克力里切出 K 块同样大小的正方形，边长必须是整数，求最大的边长。

![](posts/assets/lanqiao-chocolate.svg)

看到「**求最大值**」+「**越大越难满足**」，条件反射就该想到二分答案。

为什么能二分？因为函数是**单调**的：边长 `s` 越大，能切出的块数 `f(s)` 只会减少或不变：

```
f(s) = Σ floor(H_i / s) * floor(W_i / s)
```

我们要找的是满足 `f(s) >= K` 的最大 `s`。`f` 单调不增，所以答案左边全可行、右边全不可行——这是二分的前提。

```cpp
#include <cstdio>
#include <algorithm>
using namespace std;

const int MAXN = 100005;
int n, k;
int h[MAXN], w[MAXN];

// 边长为 s 时能切出多少块
long long count(int s) {
    long long sum = 0;
    for (int i = 0; i < n; ++i)
        sum += (long long)(h[i] / s) * (w[i] / s);
    return sum;
}

int main() {
    scanf("%d %d", &n, &k);
    int hi = 0;
    for (int i = 0; i < n; ++i) {
        scanf("%d %d", &h[i], &w[i]);
        hi = max(hi, max(h[i], w[i]));   // 边长不可能超过最大的那块
    }

    int lo = 1, ans = 0;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;    // 别写成 (lo+hi)/2，会溢出
        if (count(mid) >= k) {           // mid 可行，试试更大的
            ans = mid;
            lo = mid + 1;
        } else {
            hi = mid - 1;
        }
    }
    printf("%d\n", ans);
    return 0;
}
```

几个容易踩的坑：

- `count` 的返回值得用 `long long`。`100000 × 100000` 是 10¹⁰，早就超 `int` 了。
- `mid` 写 `lo + (hi - lo) / 2`，虽然这题 `hi ≤ 10⁵` 不至于溢出，但习惯要养好。
- 二分是「找最后一个满足条件的值」，所以可行时 `ans = mid; lo = mid + 1`，别直接 `return`。

> **考点**：二分答案的判定函数。题目不会直接告诉你「这是二分」，得自己看出单调性，并且会写一个 `check()`。

## 五、数字三角形（经典 DP）

> 给定一个 n 层的数字三角形，从顶部出发，每一步只能走到左下方或右下方的数，求一条路径使路径上数字之和最大。

![](posts/assets/lanqiao-triangle.svg)

### 为什么不能从上往下贪心

从顶部开始每次选大的那个，看起来合理，其实会掉坑：上面多拿 1，可能让下面少拿 100。贪心在这里没有最优子结构。

### 自底向上

反过来想：**假如我已经站在最底下某一格**，那从这一格出发的最大和就是它自己。再往上一层，每一格的最大和就是「自己的值 + 下方两个格子里较大的那个」：

```
dp[i][j] = a[i][j] + max(dp[i+1][j], dp[i+1][j+1])
```

一直推到顶上，`dp[0][0]` 就是答案。好处是**不用处理边界**——每个格子都有两个下方的邻居，不会越界。

```cpp
#include <cstdio>
#include <algorithm>
using namespace std;

int a[105][105];

int main() {
    int n;
    scanf("%d", &n);
    for (int i = 0; i < n; ++i)
        for (int j = 0; j <= i; ++j)
            scanf("%d", &a[i][j]);

    // 直接在原数组上改，省一个 dp 数组
    for (int i = n - 2; i >= 0; --i)
        for (int j = 0; j <= i; ++j)
            a[i][j] += max(a[i + 1][j], a[i + 1][j + 1]);

    printf("%d\n", a[0][0]);
    return 0;
}
```

拿图中的例子跑一遍：最下面一行是 `4 5 2 6 5`，往上推到第 3 行变成 `7 12 10 10`，再往上 `20 13 10`，再 `23 21`，最后 `30`。

### 如果非要自顶向下

那就得处理边界：最左列只能从正上方来，最右列只能从左上方来。代码会多出两段特判，不如自底向上干净。**两种都能做，选不容易写错的。**

> **考点**：状态定义和递推方向。想清楚「dp 值代表从这个状态出发的最优解」，方向自然就定了。

## 六、小结

四道题，四种思路：

| 题目 | 核心 | 一句话 |
| --- | --- | --- |
| 生日蜡烛 | 枚举 | 范围小就直接试 |
| 煤球数目 | 递推 | 先看相邻两项差什么 |
| 分巧克力 | 二分答案 | 求最值 + 单调 → 二分 |
| 数字三角形 | DP | 自底向上，不用特判边界 |

蓝桥杯的题不难在数据结构，难在**在考场上快速看出该用哪一类方法**。多做几道，看到「最大 / 最小」先想二分和 DP，看到「方案数」先想递推，看到网格先想 DFS / BFS，就差不多了。
