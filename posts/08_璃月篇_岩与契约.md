# 08 · 璃月篇：岩与契约

> **国家**：璃月（Liyue）　**元素**：岩（Geo）　**神明**：岩神摩拉克斯（钟离）
> **理念**：契约　**原型**：古代中国（尤其是唐宋商业都市 + 仙侠 + 神话地理）

---

## 一、地域概况

璃月位于提瓦特大陆的**东部**，地形以山地、峡谷、溶洞、港口为主。它是提瓦特最富庶的**商业与贸易中心**，货币「摩拉」即以岩神之名命名。

| 地点 | 说明 |
|---|---|
| **璃月港** | 全国核心，分「绯云坡」「吃虎岩」「玉京台」等区，是提瓦特最大的港口 |
| **群玉阁** | 天权星凝光的空中楼阁，后在对奥赛尔的战斗中坠毁 |
| **归离原** | 岩神与仙人共同建立的古代聚居地遗迹 |
| **绝云间 / 庆云顶 / 奥藏山 / 天衡山** | 仙人隐居的仙山 |
| **层岩巨渊** | 巨大的地下矿区，五百年前灾变的战场，埋有坎瑞亚遗迹与深渊污染 |
| **孤云阁** | 岩神投下的岩石形成，镇压海底的存在（奥赛尔被封印处） |
| **黄金屋 / 北国银行 / 往生堂 / 万民堂** | 金融、殡葬、饮食等标志性机构 |
| **荻花洲 / 望舒客栈 / 翠玦坡 / 灵矩关 / 遁玉陵** | 沿途地标 |

## 二、历史脉络

### 1. 魔神战争时期
- 岩神**摩拉克斯**（Morax，尊号「岩王帝君」）在魔神战争中击败多位竞争者，成为璃月的统治者。
- 被击败的魔神包括**盐之魔神赫乌莉亚**等（其残骸/遗物在璃月境内留下「盐」相关的遗迹与传说）。
- 摩拉克斯与**仙人**结盟，共同治理这片土地，确立「契约」为立国之本。

### 2. 归离集的兴废
- 摩拉克斯与仙人建立了**归离集**，作为人神共居的聚居地。
- 后来归离集毁于灾难（与魔神战争余波、自然的崩坏有关），幸存者迁往今日的璃月港。
- 归离原的遗迹至今散落着古代文明的残骸。

### 3. 若陀龙王之争
- **若陀龙王**（Azhdaha）是岩龙王，曾与摩拉克斯并肩作战，被称为「众仙之祖」。
- 后来若陀龙王因**土地的污染与疯狂**而与摩拉克斯反目，被摩拉克斯镇压封印于地下（伏龙树）。
- 这是「龙王与天理 / 七神」矛盾的又一个具体案例。

### 4. 五百年前的坎瑞亚灾变
- 坎瑞亚覆灭后，深渊魔物大举入侵，璃月同样是战场。
- **层岩巨渊**成为主战场之一，大量仙人与凡人战死；地下矿区的「黑岩厂」「地下遗迹」与坎瑞亚技术有关。
- 摩拉克斯本人参与了这场战争，仙人、夜叉都付出了巨大代价。

### 5. 「送仙典仪」与帝君之死
- 主线第一章开始时，摩拉克斯宣布「退位」，并举办**送仙典仪**。
- 典仪上摩拉克斯「遇刺身亡」——实际上是**他与愚人众「女士」的私下交易**：用神之心交换某样东西。
- 此后钟离以凡人身份「往生堂客卿」在璃月活动，成为可玩角色。

### 6. 立国与「归离原」的命名（约 3700 年前）
- 约 **3700 年前**，名为**摩拉克斯**的魔神与**仙人签订契约**，和众人建立名为「**璃月**」的国度（摩拉克斯诞生约 **6000 年前**；层岩巨渊为更早的天星坠落所成；遁玉陵遗迹远在魔神混战年代之前已存在）。可信度：【高】
- 「初，岩王降居，退海潮，立天衡，镇汐流。」民安生，开山采玉、凿岩通达、聚石为砦，名「**山辉砦**」，天衡之民多以采矿为业，往来千里皆无贫者。可信度：【高】
- **尘王魔神「归终」（哈艮图斯）**与岩王交好，设强弩拱卫天衡，曰「**归终机**」；又率民众**居天衡北**、耕田为业。其盛时阡陌交通，市镇农田远至石门不绝。归终对岩王说：「今我离民，皆安居乐业，几同归乡，莫如名之归离原。」——「**归离原**」由此得名。可信度：【高】
- **归离原的毁灭**：「后诸魔神谋位，大乱遽起。虽诸仙人奋战力保，然战事杂乱，归离原深受混战之苦，**尘神归终亦薨于其中**」（「战于归离原，彼时黑尘漫天，千岩俱裂」）；一场**洪灾**毁灭了归离原，故岩王迁其民入天衡之南，归离原自此荒废。可信度：【高】

### 7. 诸魔神与古代遗迹
- **盐之魔神赫乌莉亚**：本是并立于璃月的诸神之一，魔神战争前漫步璃月大地；因**过于温柔**的本性，**被自己的追随者刺杀**，过早退场。葬身之地很可能在「**地中之盐**」遗迹内。可信度：【中】
- **螭与轻策山**：「螭」是龙型水元素魔兽，轻策山之前是它的巢穴。传说千年以前摩拉克斯镇服为害璃月的螭兽；螭死后身躯蜷曲转为顽石、鲜血化为碧水、鳞片成为梯田，魔兽巢穴变成如今的轻策山。然螭身不死，其血凝于地、结之为石、污害世间（「螭血木」）。击败螭之后，岩王教先民制作「**岩尊像**」镇压其残余力量。可信度：【中】
- **青墟浦与天遒谷**：青墟浦遗迹在岩之神执掌璃月之前已存在；璃沙郊一带在魔神混战年代曾被大水淹没，岩山当时只是露出水面的小岛，战后水落，先民古都堡垒与神殿显露（须弥学者索拉雅研究认为属名讳不可考的魔神与其部众）。天遒谷遗迹在遥远的过去曾是繁荣集镇，似乎与**某位古老龙王的动乱**有关——传说最后是由**帝君与仙家一起将它囚禁在洞天的樊笼中**，其眷属遁逃至地下陷入深眠，等待古老龙王复苏。可信度：【中】

### 8. 仙人、甘雨与初代七星（约 3000 年前）
- 约 **3000 年前**，**甘雨**回应岩之神摩拉克斯的召唤，成为其魔神战争助力；战争结束后留在璃月帮助建设，成为**初代七星的秘书**。可信度：【高】

### 9. 天钉之后：层岩巨渊与沉玉谷先民
- **层岩巨渊倒立文明**：第一文明的一支在层岩巨渊建立倒挂的地下城市，掌握**净化深渊的圣水**之力；后因使用禁忌知识遭天罚覆灭。可信度：【中】
- **琅玕（沉玉谷先民）**：天钉降下后层岩巨渊不宜居住，沉玉谷先民自层岩巨渊迁来，筑直通高天的祭台与殿宇；其古祭场曾因葬火埋入地下、又随天钉陨落而隆起，**最终因摩拉克斯与若陀龙王厮杀造成的破坏而显露**。可信度：【中】
- **黑岩厂古国**：烽燧年代被嶙峋岩山诸部族用作避难所，有通往大地深处古国的古老甬道。可信度：【中】

### 10. 五百年前：层岩巨渊的封印与兵器变革
- 灾厄降临琉璃之地（层岩巨渊），深渊如洪流般涌出，千岩军护送众多民众疏散逃离；**五名夜叉应帝君之命与深渊的扭曲造物血战**。千岩的战士们一部分护送居民疏散，另一部分勇敢将士与断后战士一同与怪物血战；**最后一队千岩军、一些方术士和无名夜叉以不能离开的代价将漆黑兽潮封印在层岩巨渊地下的空间**，璃月方伤亡惨重，勇猛的夜叉与无畏的凡人们皆沉睡在深黑的渊薮。可信度：【高】
- **遁玉陵的由来**：遁玉之谷的坚城在数千年风霜中巍然矗立、直至五百年前仍与璃月港有往来，但随着黑色灾异自深渊而起，**遁玉居民封闭古城、背井离乡流散各地**，被封闭的城塞化成巨大空洞的陵墓——「**遁玉陵**」。可信度：【高】
- **兵器工艺变革**：灾厄之后残余魔物仍彷徨世间，为突破兵器设计的桎梏，锻造世家**云氏**与名匠**寒武**主导了璃月的**第一次兵器工艺变革**，「**试作**」兵器问世。此后名匠寒武重修兵器谱，曾为铸造**黑岩**兵器深入大地探寻矿晶，最终遭遇矿难。自某一时间起，土地不再沉寂：岩山撼动、洞窟坍塌，深埋地下的宝石金属难以开采，锻炼兵器、传承手艺之事难以为继，最终大地复归平静。可信度：【中】
- **层岩巨渊的黑蛇骑士**：化作深渊魔物的黑蛇骑士将体内的血视为「神圣之血」，天钉的力量视为不祥之物——因为深渊力量会与天空的元素力互相湮灭，故黑蛇骑士透过深渊之血消除层岩巨渊天钉的力量。可信度：【高】

## 三、主要势力

| 势力 | 核心人物 | 说明 |
|---|---|---|
| **璃月七星** | 天权星**凝光**、玉衡星**刻晴**、天枢星天叔、开阳星、瑶光星等 | 璃月的最高商政议会，七人分掌不同领域 |
| **仙人** | 削月筑阳真君、理水叠山真君、留云借风真君、萍姥姥、甘雨、烟绯、魈 | 守护璃月的远古修行者群体 |
| **夜叉** | **魈**（最后一位） | 为帝君降妖除魔的五大夜叉，其余四人皆因「业障」而死 |
| **往生堂** | **胡桃**（第七十七代堂主）、钟离 | 负责葬仪，与「生死」主题相关 |
| **北国银行** | 愚人众 | 至冬在璃月的金融据点 |
| **冒险家协会 / 商会** | 凯瑟琳、各大商会 | 璃月的经济命脉 |

**关键人物补充**：
- **钟离**：岩神摩拉克斯的凡人化身，博古通今，是「契约」的化身。
- **甘雨**：麒麟与人的混血，璃月七星的秘书，寿命极长。
- **魈**：五大夜叉仅存者，背负「业障」，长期在层岩巨渊一带除魔。
- **胡桃**：往生堂堂主，与「死亡边界」相关的特殊能力。

## 四、主线剧情（第一章）

1. **第一幕「浮世浮生千岩间」**
   - 旅行者与派蒙抵达璃月，恰逢岩王帝君在送仙典仪上「遇刺」。
   - 愚人众执行官**「公子」达达利亚**登场，主动提供帮助，引导旅行者接触仙人与七星。
   - 璃月陷入「神死了怎么办」的恐慌与权力真空。

2. **第二幕「辞行久远之躯」**
   - 旅行者深入调查刺杀事件，接触各方势力：仙人（绝云间）、七星（凝光、刻晴）、往生堂、北国银行。
   - 逐步发现愚人众在璃月有更深的布局，而刺杀真相扑朔迷离。

3. **第三幕「迫近的客星」**
   - 「公子」达达利亚为逼出岩神/引出真相，唤醒被封印在孤云阁海底的**漩涡之魔神奥赛尔**，令其袭击璃月港。
   - 仙人、七星、旅行者共同御敌；**凝光以群玉阁撞击奥赛尔**，将其再度镇压，群玉阁毁。
   - 真相揭晓：摩拉克斯并未死亡，他自愿将**神之心**交给愚人众「女士」，作为「某个契约」的交换。
   - 帝君正式退位，璃月进入**人治时代**（七星与凡人自治）。

4. **第四幕「我们终将重逢」**
   - 旅行者与**戴因斯雷布**（Dainsleif）相遇，第一次正面接触**坎瑞亚 / 深渊教团**的真相。
   - 探索坎瑞亚遗迹，见到倒吊的神像、「我们终将重逢」的誓言。
   - 这是全作主线从「各国政治」转向「世界本原」的关键转折。

## 五、璃月的世界观意义

- **契约**：璃月把「神与人之间的契约」制度化，与蒙德的「自由」形成对照。
- **神治 → 人治**：岩神主动退位，是七国中唯一完成「去神化」的国家，为后续各国提供了模板。
- **奥赛尔事件**：展示了「被封印的魔神」这一长期隐患，也展示了人类（凝光）可以用凡人之力对抗魔神。
- **夜叉与业障**：引入「除魔者被魔污染」的悲剧母题。
- **坎瑞亚的第一扇门**：第一章第四幕是坎瑞亚主线真正的开端。
