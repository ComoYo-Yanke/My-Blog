## 一、挪德卡莱概况

**挪德卡莱（Nod-Krai）**是提瓦特北境的一片**不受七神直接统治的边地**——它名义上处在至冬的影响范围内，但实际由本地势力（霜月之子、执灯人、秘闻馆等）与来自各国的亡命者共同治理，是愚人众、冒险家协会、深渊势力与各国流亡者混杂的中立地带。【中】

### 1.1 主要地点

| 地点 | 说明 |
|---|---|
| **那夏镇** | 挪德卡莱的核心城镇，主线的主要舞台。设有旅馆／酒馆「**旗舰**」、冒险家协会、秘闻馆等。 |
| **霜月之坊** | 菈乌玛所在的藏书处，同时收留并照顾生病的孩子（如加莉娜）。 |
| **叮铃哐啷蛋卷工坊** | 爱诺经营的工坊，兼具修理与情报功能。 |
| **秘闻馆** | 情报与委托的中转地。 |
| **星砂滩** | 那夏镇外围的海滩地带。 |
| **希汐岛** | 挪德卡莱周边的岛屿。 |
| **终夜长茔** | 与「月亮」相关的古代遗迹地带。 |
| **安瓦蒂尼尔湖** | 大团长法尔伽归来之处。 |

| **皮拉米达城** | 挪德卡莱城镇；第七幕战事中民众全体撤空，执灯人协助地毯式搜查与撤离。【高】 |
| **亥珀波瑞亚（海珀波瑞亚，Hyperborea）** | 古老的黄金国，**霜月之子乃其遗胤**；第六幕进入其**虚影／历史空间**寻找月神真名；其「与月亮沟通的地方」可在祈月之夜将月髓置于台上、打开通往月亮的传送门；人造月髓的技术亦以其虚影知识为基础。【高】 |
| **银月之庭** | 「少女」哥伦比娅在挪德卡莱的居所；第三幕曾遭猎月人袭击。【高】 |
| **骑士团秘密基地** | 西风骑士团在挪德卡莱的集结点，同时是**「北大陆情报网」的接头处**——情报界黑市，总部在挪德卡莱，各国皆有合作者。【高】 |

### 1.3 关键术语

| 术语 | 含义 |
|---|---|
| **月矩力** | 挪德卡莱特有的力量体系，与月亮残存的力量相关；有「月矩力光束」「月矩力充能元件」「便携式月矩力充能元件」等应用。 |
| **月髓** | 月亮的核心／本质之物。**只有三枚**：**恒月月髓**、**虹月月髓**、**人造月髓**（人造月髓为挪德卡莱方面所制）。三枚齐聚即可掌持三月权能「生、死、时、空」。第三幕的关键目标即**净化虹月的月髓**。【高】 |
| **狂猎（现象）** | 挪德卡莱的特异现象，与月、灵魂与「猎月人」的诅咒相关；有「『狂猎』现象定位图」等对应道具。 |
| **月灵** | 引导旅行者进入那夏镇的存在，外形如小生物。 |
| **三月女神** | **恒月艾莉亚（Aria）**、**霜月卡侬（Canon）**、**虹月桑娜妲（Sonata）**三位月神；三人的名字均取自**音乐体裁**；第八幕与她们正面相见。【中】 |
| **赤月** | **虹月**破碎后坠落的遗骸；虹月女神桑娜妲为延续生命与深渊结合为「赤月」，遗骸由坎瑞亚人寻得、存放于「赤月空间」。与深渊力量融合后成为部分邪眼的源头（后与至冬篇「阿蕾奇诺」设定呼应）。【中】 |
| **秘源机兵／秘源机关** | 挪德卡莱遗迹中的远古机械。 |
| **五大罪人** | 五百年前瓜分深渊力量的五人，其中**「猎月人」雷利尔**为挪德卡莱篇的主要反派线索。 |
| **狂猎／不死诅咒** | 雷利尔受不死诅咒纠缠，成为「狂猎」现象的一部分。 |
| **至高领主** | 火龙王以**秘源技术构筑的十三个「意识」**，各统治纳塔一部分土地，智慧与权力凌驾古代龙众；在与纳塔英杰的战争中逐一消亡，大部分名字已散失。已点名者：**第八席「花烛与风羽的司巫」**（曾统治花羽会一带，因背叛龙众、私下养育莉安歌而被同族处决）、**第十一席「明晨之镜」**（全名**圣龙「明晨之镜」·伊·莱拉普赫·楚伊博卢**）。【高】 |
| **「无归之诅咒」** | 第十一席在**意识分裂**后对「悖谬」、对自己设下的诅咒，即「永无归宿的诅咒」。机制：**伴随记忆而生**、深植意识之中的铁律、**一道无法移除的限制程序**；对旧道途的背离与新归宿的向往都会触发撕裂般苦痛，**善意则催生数倍痛苦**；**忘却只能暂时逃离，记忆重新堆砌即复发**。【高】 |
| **「悖谬」** | 第十一席在龙众落败后因「复仇」与「寻找新归宿」的冲突而**分裂出的两个人格之一**（另一个是宁可毁灭也不容忍自身堕落的「领主」）。它就是**伊涅芙**的本体。「领主」的意识早被剥离封印、千年前彻底灭却，但诅咒留存。【高】 |
| **月矩力（机制补充）** | 挪德卡莱特有的**原始／纯净元素力**，与「燃素」「原始胎海」同属概念谱系，旅行者判断属夜神提过的**「光界力」**；**具有牵引与排斥两种特性**，可附着于山壁、地面与通道内部并可被反向利用；当地动植物随其潮汐强弱变化。第八幕揭示其本质（见上）。【高】 |
| **光界力** | 夜神口中与「燃素」并列的力量范畴；旅行者据此判断月矩力同属此系。愚人众试验设计局文档称其目的为**「利用『光界力』制造一样武器」**。【中】 |
| **晶合石** | **蕴含／储存月矩力的矿石**；采石场事件中「晶合石完好无损，但其中所蕴藏的月矩力几乎消失殆尽」，是判定猎月人在吸收月矩力的直接证据。希汐岛最大的**神像**亦由富含月矩力的矿石（**月魂石**）雕成。【高】 |
| **汐印石** | 可用于**封印「因未知原因失活」的小型狂猎**的物件；与「每次大规模狂猎前同一地点必先出现小规模狂猎」的规律相配套，是狂猎机制的关键道具之一。【高】 |
| **月亮倒影** | **时间逆流的异空间**：其时间「以进入的那一刻为起点，向过去流淌」，每次进入抵达的现实时间点都比上一次更早。可用作跨时空传信，但须双方都掌握方法。雷利尔当年「最后掉进了再也回不来的『月亮倒影』里」；第七幕哥伦比娅亦坠入其中。【高】 |
| **人造月髓** | 第三枚月髓，由**「博士」多托雷**依**「亥珀波瑞亚的虚影」**提供的知识制造。多托雷声称「少一个月亮的话，自己造就行」。其**最终下落未在本篇交代**。【中】 |
| **月谕圣牌** | **塔罗式占卜牌阵**，牌位分「命运／往昔／当下／未来」；第六幕祈月之夜由占卜师**芭比洛斯**为哥伦比娅使用。【中】 |
| **计程仪 / 术式** | 桑多涅所制的**计程仪**可直观展示「术式」进度；「术式」指**重构规则的仪式／算式**，用于迎回哥伦比娅（第八幕）。【中】 |
| **时间之河** | 第八幕尼可语：「世界总有尽头，而时间的尽头，就是提瓦特诞生的时刻」；哥伦比娅能沿这条逆流的时间之河到达何处，取决于河流起点在哪。【中】 |
| **库塔尔／希珀** | **「库塔尔」**是挪德卡莱人对月神的称呼，**并非真名**；**「希珀」**是虹月女神桑娜妲对霜月女神的称呼（疑为霜月女神本名）。**【存疑】**【中】 |
| **赤月空间** | 封存**虹月月髓**的特殊空间，**需举行仪式才能短暂进入**；内部悬挂一轮红月、深渊气息几乎填满，**月髓不在天上而在水中的月亮倒影里**。坎瑞亚**「深秘院」**研究员**索琳蒂丝**曾在此铺设**深渊抑制装置**。【高】 |
| **两界之火** | **被这种火焰烧却的人，会在世间留下类似幽灵的「残影」**；坎瑞亚时期的人相信它**能够连接生死两界**。赤月王朝期「教养院」的**入院仪式**即以此为核心。【高】 |

## 三、逐幕脉络

### 序奏「归途」（5.8）【中】
- 开场位于**纳塔花羽会**一带，围绕**伊涅芙**的失忆与修复展开。
- 遗迹深处出现名为「**归途**」的存在；旅行者直面「**领主**」与「**明晨之镜**」。
- 首次引入**秘源机兵／秘源机关**等挪德卡莱系概念，为进入北境做铺垫。
- 道具伏笔：花型机关零件、噼哩啪啦密码筒。

### 第一幕「雪浪与苍林之舞」【中】
- 旅行者抵达**那夏镇**，由**月灵**引路。
- 介绍那夏镇的据点群：「旗舰」（旅馆／酒馆）、冒险家协会、**「叮铃哐啷蛋卷工坊」**（爱诺）、**「霜月之坊」**（菈乌玛，藏书处，并照顾生病的孩子加莉娜）。
- 接触到**霜月之子**组织、**秘闻馆**、**愚人众试验设计局**，以及**星砂滩**、**希汐岛**。
- 首次体验**月矩力**，并遭遇**「狂猎」现象**。

### 第二幕「尘与灯的挽歌」【中】
- **「少女」哥伦比娅**居住于**银月之庭**。
- 旅行者从「记忆」中挖掘真相，揭示此前伪装成血亲的诡影真身——五大罪人之一**「猎月人」雷利尔**。
- 「旗舰」酒会卧底戏：**奈芙尔**、**雅珂达**、**菲林斯**与**「执灯人」**登场。
- 雷利尔借那夏镇的大炮获得完整身躯，局势失控。

### 第三幕「不存在的国土」【中】
- **大团长法尔伽**从**安瓦蒂尼尔湖**归来。
- **「木偶」桑多涅**、**「仆人」阿蕾奇诺**登场。
- 旅行者进入**赤月所在的空间**，穿过「甬道」，**净化虹月的月髓**。

### 第四幕「回望湮灭的月光」【中】
- 深入**雷利尔**的过去：阿如村、伊阿布族、神庙。
- **戴因斯雷布**、**维瑟弗尼尔**、**索琳蒂丝**登场。
- 击败「猎月人」雷利尔，完成本章第一大段落（终曲之前的主线目标）。

### 第五幕「终北的夜行诗」【中】
- 围绕**「祈月之夜」**节庆展开。
- **艾莉丝**、魔女**尼可**等魔女会成员登场，**拉撒抹培**亦出现。
- 会见愚人众执行官的会谈段落。

### 第六幕「散于晨雾的月芒」【中】
- 哥伦比娅**找回自己的名字**。
- 「祈月之夜」的节庆场景：三位魔女的节日摊位。
- 主题从「月亮做了什么」转向「月亮是什么」，为终曲铺路。

### 第七幕「如果在冬夜，一个旅人」【中】
- **「博士」多托雷**的研究所与战斗段落。
- **镜中世界**的探索。
- **「公子」达达利亚**、**杜林**、**流浪者**登场。

### 第八幕「真实之月」【中】
- **与三月女神见面**，月亮真相的核心揭示。
- 击败**「博士」**。
- 月亮回到故乡；**哥伦比娅登月**、调查飞船、返回提瓦特。

### 第九幕「身土坏空，五蕴识转」（月之七）【中】
- 舞台转回**须弥**：**世界树异常**，**纳西妲昏迷**。
- 【高】**世界树没有从外部遭受攻击的迹象**（流浪者／阿帽的数据分析结论）；真相是多托雷**死后从世界树内部操控**它。
- 【高】**纳西妲把自己接入世界树，充当「资料流转和记录的临时终端」**，承受非人折磨后**昏迷**，元素力衰减到极度危险等级。
- 【高】**阿佩普（草龙王）**报恩出手，以**绿洲之心**为纳西妲补充草元素力；并揭示世界树**并非天理栽种**——它先于天理存在、属于提瓦特与龙族，被天理**夺走改造**以服务人类、**锚定世界的命运**。她并称「天理的规则开始松动」「水龙王已从僭越的神明手中取回权柄」。
- 涉及地点：喀万驿、缄默之殿、居尔城废墟、阿如村、赤王陵，以及**「阿如的倒影」**与**「神之棋盘」**。
- 相关角色／存在：**利露帕尔**、镇灵、**婕德**、**阿佩普**。

### 第十幕「虚空劫灰往世书」（月之七）【中】
- **原显示任务名为「道成千壑，因果异灭」（博士伪造），冲破幻境后改为真名「虚空劫灰往世书」。**【高】
- 子任务：幽暗时分／妄念与真知的通天塔／虚空劫灰往世书／你的往事如一座花园。
- 潜入**净善宫**、**桥接进入世界树**，与**「博士」多托雷**和**「富人」潘塔罗涅**对话。
- 【高】**四影现身**：**死之执政、时之执政、生之执政首次在主线正文中现身**，先后与纳西妲对话并**默许她行使「毁灭世界树的最高权限」**（空之执政未现身）。时之执政原话：「**世界樹乃原初的提瓦特之樹，是天理用以維護命運的重要命脈。七執政自天理手中接過權柄，應當遵從它、敬仰它。**」
- 【高】**世界树被火神之心焚烧七天七夜，仅剩地表以下的部分**；**「阿如」成为新的世界树**，天使**尼可**将纳西妲与世界树的连结**嫁接到阿如**——纳西妲的**存在根基从此与阿如绑定**。
- 【高】**火神之心失踪**：残骸中全力搜寻无果，「**连被化为灰烬的痕迹都没有**」——未解伏笔。
- 【高】**多托雷（真名贊迪克）死亡**：他**将灵魂一分为二**（一半在挪德卡莱战败、一半存于北国银行金库），目的是**「从死亡中进入世界树，在世界之中再造一个新世界」**，最终被纳西妲与火神之心焚毁。艾尔海森的**「阿如计划」**（改造阿如并与虚空合并、以全民终端制造负荷使世界树停摆）是本幕战术核心。
- 【高】**「富人」潘塔罗涅**：旧名**費奧潘**，曾经商失败被黑帮陷害、遭当实验体卖给医学实验室，**多托雷一念救他一命并为他换肺**；此行是履行契约把多托雷「最后的资料备份放入地脉」，与多托雷告别后**未死**。

### 月亮的终局：哥伦比娅与三月权能

- **哥伦比娅·希珀塞莱尼娅（Columbina Hyposelenia）**＝**霜月女神**、愚人众第三席「少女」，别名**空月归乡／十字路的主人**。【高】
- 终局：她**将霜月拖入虚假之天内**以锚定自身存在，并**通过月亮的倒影回到过去，从三月女神手中接过三月权能，成为提瓦特唯一的「三月女神」**。【中】
- **三个月亮坠落的后果**：
  - **恒月坠落 → 潮汐变动 → 大洪水**（提瓦特多国都有洪水记载）。【中】
  - **虹月破碎 → 遗骸即坎瑞亚的「赤月」**：**赤月王朝**凭赤月之光使炼金术飞速发展 → 学者发现**赤月只是四影管辖的三月之一** → 大规模起义、赤月王朝贵族几乎被屠杀殆尽 → **黑日王朝**建立、**赤月被贬为「厄月」**；赤月王朝「**两界之火**」的后代即**阿蕾奇诺**。（「赤月只是四影管辖的三月之一」属玩家考据，【存疑】）【中】
  - **双月（霜月）未破碎，而是停转并隐去身形**；挪德卡莱因此有「**双月之子**」之说，当地居民能使用比七元素力更古老的特殊力量。【中】
- **月神成为「异端神」**：**尼伯龙根**令提瓦特空中升起三明月、使月神初诞，其后**囚禁她们、把月亮改造为对抗天理的「天基武器」**；三人在**葬火之战**中死亡，**除霜月外两月被击碎、霜月被扔到天外** → **月亮自此不属于提瓦特**；葬火之战后月神不被提瓦特承认、存在失去根基，成为「**异端神**」，哥伦比娅自降生起力量被缓慢剥夺正是承受不了世界的排斥。【中】

## 四、主题与意义

- **月亮是被毁掉的第三块拼图**：提瓦特的「天」是虚假之天，而原本悬挂于其上的三月已被击碎／抛离。挪德卡莱篇正面处理了这一层的后果：被击碎的月亮并没有消失，它的碎片、记忆与权能仍在北境的土地上运作（月矩力、月髓、狂猎）。
- **「记忆」是可被夺取与篡改的资源**：本章反复使用「记忆挖掘」「名字的丢失与找回」这类机制，与后续至冬篇「天理可操纵记忆」「女皇持转录棱镜」的设定构成同一条线索。
- **罪人与不死诅咒**：雷利尔的悲剧说明，五百年前瓜分深渊力量的人并未真正死去，而是以诅咒的形式被留在世界上——这与纳塔「队长」卡皮塔诺的不死诅咒互为镜像。
- **世界树的脆弱**：第九、十幕把舞台从北境拉回须弥，说明「月亮问题」最终会落到**世界树**这一记录与改写提瓦特的总枢纽上，并为至冬篇「世界树被焚」埋线。
